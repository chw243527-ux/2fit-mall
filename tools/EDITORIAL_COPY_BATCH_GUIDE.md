# 기성품 에디토리얼 카피 일괄 갱신 가이드

이 스크립트는 기성품 상품의 **상품명·카테고리·색상·소재**를 읽고, 상세페이지 히어로에 표시되는 라벨·메인 타이틀·강조 문구·서브 문구를 일괄 생성합니다. 단체주문 전용 상품(`isGroupOnly = true`)은 조회 및 갱신 대상에서 제외됩니다.

> 이 스크립트는 정기 실행 도구가 아니라, 신상품 등록 후 또는 카피 정책 변경 시 관리자가 직접 실행하는 일회성 관리 도구입니다. 기본 실행은 실제 데이터에 쓰지 않는 **미리보기 모드**입니다.

## 운영 방식 비교

| 방식 | 작동 방식 | 장점 | 고려할 점 |
|---|---|---|---|
| **일괄 카피 스크립트** | Firestore의 각 기성품 문서에 `editorial*` 필드를 저장합니다. | 상품마다 생성 결과가 데이터로 남고, 특정 상품만 잠글 수 있습니다. 향후 관리자 기능으로 확장하기 좋습니다. | Firebase 서비스 계정에 Firestore 읽기·쓰기 권한이 필요합니다. 처음에는 미리보기 후 실제 반영을 한 번 실행해야 합니다. |
| **앱 내부 기본 카피 규칙** | 상세페이지 코드가 상품명·색상을 기준으로 카피를 즉시 생성합니다. | 별도 데이터 갱신 없이 기본 카피가 표시됩니다. | 수동으로 카피를 고정하거나 상품별 문구를 이력 관리하기 어렵습니다. |

현재 쇼핑몰은 두 방식을 함께 지원합니다. Firestore에 일괄 생성된 카피가 있으면 그것을 먼저 표시하고, 없는 상품에는 기존 앱 내부 기본 카피 규칙을 사용합니다.

## 카피·소재 매핑 기준

| 상품 유형 | 소재 정보 | 생성 방향 |
|---|---|---|
| 싱글렛·라운드티 | 폴리에스터 92% / 라이크라 8% | 가벼운 러닝·준비된 움직임 중심 |
| 골지타이즈·골지 하의 | 나일론 75% / 라이크라 25% | 신축성·안정적인 핏 중심 |
| 에어로브라이트 상품 | 에어로브라이트 원단(펄원단), 폴리에스터 78% / 크레오라 22% | 가벼움·유연한 움직임 중심 |
| 크롭탑·삼각·원피스·브라이트 상품 | 브라이트 원단(펄원단), 폴리에스터 80% / 크레오라 20% | 빛감·유연한 움직임 중심 |
| 그 외 기성품 | 상품의 기존 `material` 값 또는 안내 문구 | 범용 2FIT 퍼포먼스 카피 |

색상이 있는 상품은 블랙·화이트·오렌지·그린·블루·틸블루·핑크·퍼플에 따라 타이틀과 에디션 라벨을 다르게 생성합니다.

## 사전 준비

프로젝트 루트에서 의존성을 설치합니다. 서비스 계정 JSON 파일은 저장소에 커밋하지 말고, 안전한 로컬 경로에 보관해야 합니다.

```bash
cd /home/ubuntu/2fit-mall/functions
npm ci
```

서비스 계정에는 `fit-mall` 프로젝트의 `products` 컬렉션을 읽고 쓸 권한이 필요합니다. 현재 자동 배포용 서비스 계정은 Firestore 규칙 배포 권한이 없어도 프런트엔드 배포에는 문제가 없지만, 이 스크립트로 실제 데이터 변경을 하려면 별도의 Firestore 쓰기 권한이 필요합니다.

## 1단계: 미리보기 실행

아래 명령은 Firestore 데이터를 **변경하지 않습니다**. 갱신 대상과 생성될 카피를 터미널에 출력하므로, 반드시 먼저 실행해 결과를 확인합니다.

```bash
cd /home/ubuntu/2fit-mall
GOOGLE_APPLICATION_CREDENTIALS=/절대경로/firebase-service-account.json \
  node tools/batch-update-editorial-copy.js
```

## 2단계: 실제 반영

미리보기 결과가 적절한 경우에만 `--apply`를 추가합니다. 이 명령은 기성품 문서에 아래 필드를 저장합니다.

```bash
cd /home/ubuntu/2fit-mall
GOOGLE_APPLICATION_CREDENTIALS=/절대경로/firebase-service-account.json \
  node tools/batch-update-editorial-copy.js --apply
```

| 저장 필드 | 용도 |
|---|---|
| `editorialLabel` | 히어로 상단의 상품군·색상 라벨 |
| `editorialTitle` | 두 줄 메인 타이틀 |
| `editorialAccent` | 강조 영문 문구 |
| `editorialSubtitle` | 한국어 서브 문구 |
| `editorialMaterialKey` | 카피 생성에 쓰인 소재 규칙 식별자 |
| `editorialMaterialText` | 카피 생성 당시의 소재 정보 |
| `editorialSource` | 생성 도구 버전 (`material-copy-batch-v1`) |
| `editorialUpdatedAt` | 실제 갱신 시각 |

## 개별 문구 보호 및 재생성

특정 상품의 문구를 수동으로 유지하려면 해당 Firestore 상품 문서에 `editorialLocked: true`를 추가합니다. 이 경우 일괄 스크립트는 해당 상품을 건너뜁니다. 잠긴 상품까지 다시 생성해야 할 때만 아래처럼 `--force`를 사용합니다.

```bash
GOOGLE_APPLICATION_CREDENTIALS=/절대경로/firebase-service-account.json \
  node tools/batch-update-editorial-copy.js --apply --force
```

비활성 상품까지 포함해야 할 때는 `--include-inactive`를 추가할 수 있습니다. 일반 운영에서는 활성 기성품만 갱신하는 기본 설정을 권장합니다.

## 적용 확인

실제 반영 후에는 기성품 상세페이지를 새로고침하여 검정 히어로 영역의 라벨·타이틀·강조 문구·서브 문구가 변경되었는지 확인합니다. 단체주문 상품은 `TEAM ORDER / CUSTOM MADE` 흐름을 그대로 유지하며, 기성품 싱글렛 단품의 200장 한정 메시지도 변경되지 않습니다.
