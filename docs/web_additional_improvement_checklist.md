# 2FIT Mall 웹 버전 추가 보완 체크리스트

작성 기준: 최신 웹 배포 커밋 `3beb538` 및 현재 운영 검수 항목

이 문서는 자동화된 빌드·배포·보안 검증과 별도로, 실제 PC·태블릿·모바일 브라우저에서 확인하거나 추가 보완해야 할 항목을 정리한 문서입니다. 체크되지 않은 항목은 재현 조건과 화면 캡처를 함께 기록한 뒤 수정 여부를 결정합니다.

## 1. 출시 차단 항목

| 상태 | 점검 항목 | 합격 기준 | 비고 |
|---|---|---|---|
| ☐ | 결제 취소 후 복귀 | 결제 취소 뒤 Checkout 화면으로 돌아오며 결제 버튼이 다시 활성화됨 | 최근 수정 영역 |
| ☐ | 결제 재시도 | 취소 또는 실패 후 새 결제 시도가 정상적으로 열림 | 이전 iframe 상태를 재사용하지 않음 |
| ☐ | 결제 성공 중복 방지 | 성공 콜백 새로고침·재접속 시 주문이 한 번만 생성됨 | 주문 1건·재고 1회 차감 |
| ☐ | 결제 금액 검증 | 화면 금액과 무관하게 서버가 주문 금액을 재계산하고 검증함 | 결제 함수 직접 호출 포함 |
| ☐ | 품절 결제 차단 | 장바구니에 담은 뒤 재고가 0이 되면 결제가 거부됨 | 사용자에게 재고 부족 안내 |
| ☐ | 배송지 입력 검증 | 주소·상세주소·주문자명·전화번호가 누락되면 결제가 시작되지 않음 | 국내·해외 배송 각각 확인 |
| ☐ | 개인정보 접근 차단 | 일반 사용자가 다른 사용자의 주문·주소·첨부파일을 조회할 수 없음 | Firestore·Storage 모두 확인 |
| ☐ | 관리자 접근 차단 | 관리자 claim이 없는 계정이 관리자 화면과 함수를 실행할 수 없음 | URL 직접 접근 포함 |

## 우선 처리 순서

1. 결제 취소·재시도·중복 주문·품절 결제를 확인합니다.
2. 재고 변경과 재입고 알림을 실제 운영 데이터로 검증합니다.
3. Firestore·Storage·관리자 권한 경계를 확인합니다.
4. 주소 저장과 주문자 정보가 주문·관리자·PDF에 일치하는지 확인합니다.
5. 계약 기준과 정산 배분 비율을 확인합니다.
6. 단체주문 옵션과 PDF를 카테고리별로 검증합니다.
7. PC·태블릿·모바일 반응형과 이미지 로딩을 확인합니다.
8. 작업 트리·캐시·롤백·배포 후 모니터링을 확인합니다.
