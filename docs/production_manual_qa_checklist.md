# 2FIT Mall 쇼핑몰 전체 직접 점검 체크리스트

이 문서는 자동화된 정적 분석·보안 검사·CI/CD 검증으로 확인하기 어려운 항목을 실제 사용자 계정, 실제 기기, 실제 운영 데이터로 확인하기 위한 최종 체크리스트입니다. 각 테스트에는 테스트 시각, 기기·OS·브라우저 또는 앱 버전, 계정 유형, 상품 ID, 주문번호를 기록합니다.

> **운영 중단 기준:** 결제 금액 불일치, 결제 성공 후 주문 미생성, 중복 주문, 재고 미차감 또는 과다 차감, 품절 상품 구매, 다른 사용자의 주문·개인정보 노출, 결제 앱 복귀 실패가 발생하면 공개 운영을 중단하고 원인을 해결합니다.

| 테스트 상품 | 기성품, 기능성 상품, 단체주문 상품, 품절 옵션 준비 | ☐ |
| 기기 | Android 휴대폰, iPhone 또는 모바일 브라우저, 태블릿, PC 준비 | ☐ |

## 2. 일반 사용자 핵심 흐름

일반 계정으로 로그인한 뒤 홈, 카테고리, 상품 상세, 장바구니, 주문서, 주문 완료, 마이페이지를 순서대로 이동합니다. 새로고침과 로그아웃 후 재로그인을 각각 수행합니다.

| 테스트 | 합격 기준 | 결과 |
|---|---|---|
| 로그인·로그아웃 | 로그인 상태가 정상 유지되고 로그아웃 후 보호 화면이 노출되지 않음 | ☐ |
| 홈 화면 | 배너·상품 목록·카테고리·팝업이 정상 표시됨 | ☐ |
| 카테고리 이동 | 싱글렛, 라운드티, 기능성, 아우터 등 카테고리 이동이 정상임 | ☐ |
| 상품 검색 | 검색어 입력, 결과 표시, 검색 결과 초기화가 정상임 | ☐ |
| 상품 상세 | 이미지, 상품명, 가격, 색상, 사이즈, 재고, 구매 버튼이 정상임 | ☐ |
| 팝업 | 팝업이 화면 안에 표시되고 닫기·다시 열기가 정상임 | ☐ |
| 마이페이지 | 프로필, 주문 내역, 주문 상세, 찜·쿠폰 영역이 정상임 | ☐ |
| 뒤로가기·새로고침 | 이전 화면 이동과 새로고침 후 상태 복원이 정상임 | ☐ |

## 3. 상품 옵션·장바구니

색상이 두 개 이상 등록된 기성품을 사용합니다. 사이즈별로 다른 색상을 각각 선택해 장바구니에 담고, 기능성 상품과 단체주문 상품도 별도로 담습니다.

| 테스트 | 합격 기준 | 결과 |
|---|---|---|
| 기성품 색상 | 등록된 색상만 선택 가능하고 설정되지 않은 색상 추가금은 0원임 | ☐ |
| 사이즈·색상 조합 | 사이즈별로 선택한 색상 조합이 각각 보존됨 | ☐ |
| 기능성 상품 옵션 | 선택한 사이즈와 색상이 장바구니에 모두 표시됨 | ☐ |
| 단체주문 장바구니 | 주문서 선택사항이 보존되고 옵션 확인 버튼으로 주문서에 재진입 가능함 | ☐ |
| 장바구니 담기 완료 | 중앙 추천 팝업에 추천 상품이 표시됨 | ☐ |
| 장바구니 이동 | 팝업의 장바구니 보기 버튼이 활성화되고 장바구니로 이동함 | ☐ |
| 쇼핑 계속하기 | 팝업의 쇼핑 계속하기 버튼이 닫히고 상품 탐색을 계속할 수 있음 | ☐ |
| 옵션 표시 | 장바구니에 상품별 사이즈·색상·기장·성별·주머니 등 선택 옵션이 표시됨 | ☐ |
| 수량 변경 | 수량, 재고, 금액이 즉시 갱신되고 재고보다 많이 선택되지 않음 | ☐ |
| 빈 장바구니 | 쇼핑 계속하기 버튼이 활성화되고 홈 또는 상품 목록으로 이동함 | ☐ |
| 품절 동기화 | 다른 화면에서 재고를 0으로 바꾸면 장바구니 상품에도 품절 상태가 반영됨 | ☐ |

## 4. 배송지·결제·주문

실제 결제는 사전에 금액과 환불 가능 여부를 확인한 테스트 상품으로만 수행합니다.

| 테스트 | 합격 기준 | 결과 |
|---|---|---|
| 주소 검색 모바일 | 주소 검색 결과 선택, 우편번호, 기본 주소, 상세 주소 입력이 정상임 | ☐ |
| 주소 검색 태블릿 | 주소 검색 화면에서 주문서로 정상 복귀함 | ☐ |
| 결제 금액 | 상품 금액, 옵션 금액, 할인, 배송비, 최종 금액이 모두 일치함 | ☐ |
| Android 결제 복귀 | 결제 앱에서 복귀한 뒤 무한 로딩 없이 주문 완료 화면이 표시됨 | ☐ |
| 태블릿 결제 복귀 | 결제 완료 상태와 주문번호가 저장됨 | ☐ |
| 결제 취소·실패 | 주문이 확정되지 않고 부당한 재고 차감이 없음 | ☐ |
| 빠른 중복 클릭 | 주문이 한 건만 생성되고 재고가 한 번만 차감됨 | ☐ |
| 새로고침·뒤로가기 | 결제 완료 후 재호출해도 중복 주문이 생성되지 않음 | ☐ |
| 주문 완료 | 주문번호, 상품, 옵션, 수량, 결제 금액, 배송지가 정확함 | ☐ |
| 사용자 주문 상세 | 기성품·기능성·단체주문 옵션이 모두 표시됨 | ☐ |

## 5. 재고·재입고 알림

관리자 계정과 일반 사용자 계정 또는 두 개의 브라우저를 동시에 사용합니다.

| 테스트 | 합격 기준 | 결과 |
|---|---|---|
| 사이즈 재고 수정 | `stockData`, `sizeStocks`, `stockCount`가 일관되게 변경됨 | ☐ |
| 색상 재고 수정 | 색상별 재고가 공개 화면에 반영됨 | ☐ |
| 일괄 재고 수정 | 선택한 모든 상품·옵션에 수량이 적용됨 | ☐ |
| 실시간 반영 | 상품 목록, 상세, 장바구니에 변경 수량이 새로고침 또는 짧은 지연 후 반영됨 | ☐ |
| 0→양수 | 품절 해제와 구매 가능 상태가 모든 화면에 반영됨 | ☐ |
| 음수 방지 | 재고가 음수로 저장되지 않음 | ☐ |
| 재입고 신청 | 품절 옵션에서 신청 성공 메시지와 데이터 생성이 확인됨 | ☐ |
| 재입고 알림 | 0에서 양수로 변경할 때 신청 사용자에게 알림이 한 번 발송됨 | ☐ |
| 알림 클릭 | 알림을 누르면 해당 상품·옵션 화면으로 이동함 | ☐ |
| 알림 권한 거부 | 앱이 멈추지 않고 권한 설정 안내를 표시함 | ☐ |

| 발주용 PDF | 가격과 고객 민감정보를 제외하고 제작 정보가 표시됨 | ☐ |
| 관리자 연동 | 관리자 주문 상세에서 주문서와 동일한 정보가 표시됨 | ☐ |

## 9. 권한·보안 직접 확인

| 테스트 | 합격 기준 | 결과 |
|---|---|---|
| 일반 계정의 관리자 접근 | 관리자 URL·메뉴·API 접근이 거부됨 | ☐ |
| 다른 사용자 주문 접근 | 주문 ID를 바꿔도 다른 사용자 주문이 보이지 않음 | ☐ |

## 10. 최종 공개 판정

다음 조건을 모두 만족할 때 단계적 실사용 공개를 진행합니다.

1. P0인 로그인, 배송지, 결제, 주문 생성, 금액 검증, 재고 차감이 모두 통과합니다.
2. 기성품·기능성·단체주문 옵션이 장바구니와 주문 상세에 누락 없이 보존됩니다.
3. 재고 0에서 양수로 변경할 때 공개 화면과 재입고 알림이 정상입니다.
4. 모바일·태블릿·PC에서 핵심 조작을 방해하는 겹침이나 잘림이 없습니다.
5. 일반 사용자가 관리자 데이터나 다른 사용자의 주문·첨부파일을 볼 수 없습니다.
6. 단체주문 PDF와 관리자 주문 상세가 주문서 입력값과 일치합니다.
7. 첫 공개 후 최소 30분 동안 결제 승인, 주문 상태, 재고, 오류 로그, 모니터링 결과를 확인합니다.

문제 발생 시 반복 클릭하지 말고 다음 정보를 함께 기록합니다: 발생 시각, 기기·OS, 브라우저·앱 버전, 네트워크, 계정 유형, 상품·옵션, 주문번호, 재현 절차, 기대 결과, 실제 결과, 스크린샷, 오류 로그.
