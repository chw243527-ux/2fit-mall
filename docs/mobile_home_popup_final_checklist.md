## 1. 첫 화면 로딩

- [ ] 주소 접속 후 흰 화면이나 무한 로딩 없이 홈 화면이 열린다.
- [ ] 로고, 검색, 장바구니, 언어 선택 버튼이 화면 안에 표시된다.
- [ ] 홈 상단에 헤더가 한 번만 표시된다.
- [ ] 헤더와 메인 배너 사이에 중복 행이나 비정상적인 빈 공간이 없다.
- [ ] 배너 이미지가 로딩될 때 레이아웃이 크게 흔들리지 않는다.
- [ ] 이미지 로딩 실패 시 빈 박스 대신 준비된 대체 화면이나 배경이 표시된다.
- [ ] 세로 화면에서 가로 스크롤이 생기지 않는다.

## 2. 모바일 헤더

- [ ] 메뉴 버튼을 누르면 카테고리 드로어가 열린다.
- [ ] 드로어를 연 뒤 닫기 또는 바깥 영역 터치로 정상적으로 닫힌다.
- [ ] 로고를 누르면 홈 상단으로 이동하거나 홈 화면이 유지된다.
- [ ] 검색 버튼을 누르면 검색 입력 UI가 열린다.
- [ ] 검색 입력창이 키보드에 가려지지 않는다.
- [ ] 검색을 실행하면 결과 화면으로 이동하고 뒤로 가기로 홈에 돌아온다.
- [ ] 장바구니 버튼과 상품 개수 뱃지가 겹치지 않는다.
- [ ] 언어 버튼이 화면 가장자리에서 잘리지 않는다.
- [ ] 화면 가로 방향으로 전환해도 헤더 요소가 겹치거나 사라지지 않는다.

## 3. 메인 배너

- [ ] 배너 이미지가 원본 비율을 크게 왜곡하지 않는다.
- [ ] 배너의 텍스트가 이미지 밖으로 밀리거나 배경과 겹치지 않는다.
- [ ] 좌우 스와이프로 다음 배너와 이전 배너가 이동한다.
- [ ] 자동 슬라이드가 동작하며 사용자가 터치하는 동안 화면이 갑자기 바뀌지 않는다.
- [ ] 페이지 인디케이터가 이미지나 버튼을 가리지 않는다.
- [ ] 배너의 CTA 버튼을 누르면 지정된 상품·카테고리·쿠폰 화면으로 이동한다.
- [ ] 로그인하지 않은 상태에서도 공개 배너와 상품을 볼 수 있다.
- [ ] 배너 이미지가 없는 경우에도 홈 화면 구조가 깨지지 않는다.

## 4. 공지 팝업

공지 팝업이 활성화된 테스트 데이터를 준비한 뒤 홈 화면에 진입한다.

- [ ] 공지 팝업이 홈 진입 시 한 번만 표시된다.
- [ ] 팝업 외곽 모서리가 각진 사각형으로 표시된다.
- [ ] 팝업 이미지가 등록된 경우 이미지가 실제로 표시된다.
- [ ] 이미지의 위·아래가 잘리지 않고, 화면 높이를 모두 차지하지 않는다.
- [ ] 세로 이미지와 가로 이미지에서 제목·본문 영역이 화면 밖으로 밀리지 않는다.
- [ ] 이미지가 없는 공지는 자동 테마 배경 또는 대체 콘텐츠가 표시된다.
- [ ] 닫기 버튼이 이미지 위에서 잘 보이고 터치하기 쉽다.
- [ ] 여러 공지가 있을 때 좌우 이동 또는 페이지 전환이 정상 동작한다.
- [ ] 제목과 본문이 긴 경우 줄바꿈되며 화면 밖으로 넘치지 않는다.
- [ ] ‘오늘 하루 보지 않기’를 선택하면 같은 기기에서 즉시 다시 표시되지 않는다.
- [ ] 공지 팝업을 닫은 뒤 홈 화면 스크롤 위치와 배너 상태가 정상이다.
- [ ] 팝업 바깥을 눌렀을 때 닫히는 정책이 의도한 대로 동작한다.

## 5. 쿠폰 팝업

쿠폰 팝업이 활성화된 테스트 계정과 쿠폰 데이터를 준비한다.

- [ ] 쿠폰 팝업 외곽 모서리가 각진 사각형으로 표시된다.
- [ ] 모바일 바텀시트 상단에 불필요한 둥근 모서리가 없다.
- [ ] 쿠폰 목록이 화면 너비를 넘지 않는다.
- [ ] 쿠폰명, 할인 내용, 사용 조건, 만료일이 잘리지 않는다.
- [ ] 다운로드 버튼을 한 번 누르면 처리 중 상태가 표시된다.
- [ ] 다운로드 버튼을 빠르게 여러 번 눌러도 쿠폰이 중복 발급되지 않는다.
- [ ] 다운로드 완료 후 상태가 즉시 변경된다.
- [ ] 소진된 쿠폰은 다운로드 불가 상태로 표시된다.
- [ ] 쿠폰 팝업을 닫은 뒤 홈 화면을 계속 사용할 수 있다.
- [ ] 쿠폰이 없는 경우 빈 상태 안내가 자연스럽게 표시된다.

## 6. 상품 섹션과 카드

- [ ] 기성품 베스트 상품 카드가 이미지·상품명·색상·가격 순서로 정상 표시된다.
- [ ] 단체주문 전용 상품 카드가 다른 상품 카드와 의도한 디자인으로 통일된다.
- [ ] 상품 이미지에 비정상적인 둥근 모서리나 잘림이 없다.
- [ ] 긴 상품명이 카드 높이를 깨뜨리지 않는다.
- [ ] 색상 뱃지와 가격이 상품명 또는 이미지와 겹치지 않는다.
- [ ] 상품 카드를 누르면 올바른 상세페이지로 이동한다.
- [ ] 홈 화면의 ‘전체 보기’ 버튼이 올바른 카테고리로 이동한다.
- [ ] 상품이 없는 섹션은 빈 공간만 남기지 않고 적절한 상태를 표시한다.
- [ ] 상품 목록을 빠르게 스크롤해도 이미지가 깜빡이거나 화면이 멈추지 않는다.

## 7. 팝업에서의 화면 방향·접근성

- [ ] 팝업이 열린 상태에서 세로·가로 방향 전환 후 레이아웃이 유지된다.
- [ ] 시스템 글자 크기를 크게 설정해도 제목과 버튼이 겹치지 않는다.
- [ ] 터치 가능한 닫기·다운로드·CTA 영역이 충분히 크다.
- [ ] 팝업의 텍스트와 배경 색상 대비가 충분하다.
- [ ] 화면 확대 상태에서 콘텐츠가 잘리지 않고 스크롤할 수 있다.
- [ ] 키보드가 열린 상태에서도 입력창과 주요 버튼을 사용할 수 있다.
- [ ] 뒤로 가기 또는 스와이프 뒤로 가기 동작이 팝업을 먼저 닫는다.

## 8. 네트워크와 복귀 시나리오

- [ ] 홈 로딩 중 네트워크를 잠시 끊었다가 복구해도 화면이 복구된다.
- [ ] 팝업 이미지 로딩 중 네트워크가 끊겨도 앱이 멈추지 않는다.
- [ ] 배너나 팝업 이미지 요청 실패가 원시 서버 오류로 노출되지 않는다.
- [ ] 다른 앱으로 이동했다가 돌아와도 홈 화면이 흰 화면으로 바뀌지 않는다.
- [ ] 브라우저를 백그라운드에 보냈다가 복귀해도 팝업이 중복 표시되지 않는다.
- [ ] 새로고침 후 활성 배너와 공지 팝업 데이터가 다시 로드된다.

## 9. 운영 데이터 검증

- [ ] 관리자에서 등록한 팝업 이미지가 고객 홈 화면에 표시된다.
- [ ] 관리자에서 팝업을 비활성화하면 고객 화면에서 더 이상 표시되지 않는다.
- [ ] 팝업 노출 기간 시작 전에는 표시되지 않는다.
- [ ] 팝업 노출 기간 종료 후에는 표시되지 않는다.
- [ ] 팝업 우선순위가 설정된 순서대로 적용된다.
- [ ] 이미지 교체 후 이전 이미지가 캐시 때문에 계속 표시되지 않는다.
- [ ] 팝업 제목·본문 수정 후 고객 화면에 최신 내용이 표시된다.

## 10. 즉시 실패로 판정할 문제

다음 문제 중 하나라도 발생하면 실제 사용자 공개를 보류한다.

- 홈 화면이 흰 화면 또는 무한 로딩 상태가 됨
- 헤더가 두 번 표시되거나 핵심 버튼이 겹침
- 팝업 이미지가 저장되지 않거나 다른 이미지가 표시됨
- 팝업 닫기 버튼을 누를 수 없음
- 팝업이 화면 밖으로 나가 닫거나 스크롤할 수 없음
- 상품 카드 또는 배너를 눌렀을 때 잘못된 화면으로 이동함
- 쿠폰이 한 번의 터치로 여러 번 발급됨
- 네트워크 복귀 후 홈 화면이 복구되지 않음
- 다른 사용자의 팝업 상태나 개인정보가 노출됨

## 최종 판정

P0 항목인 홈 로딩, 단일 헤더, 팝업 이미지 표시, 닫기 동작, 배너·상품 이동이 모두 통과해야 한다. P1 항목인 쿠폰 다운로드, 방향 전환, 네트워크 복귀, 관리자 팝업 데이터 반영까지 통과하면 모바일 홈과 팝업 UI의 운영 공개를 승인할 수 있다. 테스트 결과는 기기별로 기록하고, 실패한 화면은 기기명과 재현 순서를 함께 남긴다.
