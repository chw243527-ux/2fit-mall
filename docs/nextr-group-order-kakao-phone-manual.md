## 8. 상담 후 카드 결제를 원하는 경우의 처리 절차

카카오채널 또는 전화 상담을 마친 고객이 카드 결제를 원하면 다음 순서로 처리합니다.

### 8-1. 결제수단 변경 사실 확인

상담자는 먼저 단체 할인 조건을 다시 고지합니다.

> “카드 결제를 선택하시면 현금 계좌이체 전용 단체 할인가는 적용되지 않습니다. 카드 결제 기준의 일반 결제 금액으로 최종 견적을 다시 안내해 드리겠습니다.”

5~9장 주문은 42,000원, 10장 이상 주문은 39,000원 단가가 **현금 계좌이체 결제에만 적용**됩니다. 카드 결제 시에는 해당 단가를 사용하지 않고, 회사가 정한 카드 결제 기준 금액으로 재계산합니다.

### 8-2. 카드 결제용 최종 견적 재작성

기존 계좌이체 견적을 그대로 카드 결제로 전환하지 말고, 결제수단을 카드로 표시한 새 견적을 작성합니다.

```text
[NEXTR 카드 결제용 최종 견적]

단체명:
상품명:
총 수량:
사이즈별 수량:
색상:
커스텀 내용:

결제수단: 카드 결제
적용 단가: 카드 결제 기준 단가
상품 금액:
배송비:
커스텀 비용:
최종 결제 금액:

※ 현금 계좌이체 전용 단체 할인가는 카드 결제에 적용되지 않습니다.
※ 결제 전 상품·수량·사이즈·커스텀·배송지 내용을 최종 확인해 주세요.
```

카드 수수료를 별도로 고객에게 부담시키는 경우에는 관련 법령, 카드사 가맹점 약관, 세무·회계 기준을 먼저 확인하고 회사 정책에 따라 처리해야 합니다. 별도 확인 없이 임의로 “카드 수수료”를 추가하거나 계좌이체를 강요하지 않습니다.

### 8-3. 결제 방법

카드번호, 유효기간, CVC, 비밀번호 등 카드 정보를 카카오채널이나 전화로 받지 않습니다.

가능한 방식 중 하나를 사용합니다.

1. 쇼핑몰에서 고객별 상품·수량·커스텀 내용을 반영한 결제 링크 발급
2. 고객 전용 비공개 상품 또는 주문서를 생성한 뒤 안전한 결제 페이지 링크 전달
3. 쇼핑몰의 표준 결제 화면에서 주문하도록 안내
4. 결제대행사가 제공하는 공식 결제 링크 사용

상담자는 고객에게 다음처럼 안내합니다.

> “카드 정보는 채팅이나 전화로 받지 않습니다. 최종 견적 확인 후 공식 결제 페이지 링크를 보내 드리겠습니다. 링크에서 카드 결제를 완료해 주세요.”

### 8-4. 결제 전 고객 확인 문구

> “최종 주문 내용을 확인하겠습니다. [상품명] [수량]장, 사이즈 [사이즈별 수량], 색상 [색상], 커스텀 [내용], 배송지 [배송지]이며 카드 결제 금액은 총 [금액]원입니다. 현금 계좌이체 전용 단체 할인가는 카드 결제에 적용되지 않습니다. 이 내용으로 결제 링크를 보내 드릴까요?”

고객이 동의한 뒤에만 결제 링크를 발급합니다.

### 8-5. 결제 확인 후 처리

결제 완료 화면만으로 제작을 시작하지 말고, 결제 시스템 또는 관리자 주문 화면에서 다음을 확인합니다.

- 주문번호
- 결제 상태가 최종 승인 또는 결제 완료인지 여부
- 결제 금액이 견적 금액과 일치하는지 여부
- 주문자명과 연락처
- 상품·수량·사이즈·색상
- 커스텀 요청 및 첨부 파일
- 배송지
- 결제 취소·실패·부분 승인 여부

검증이 완료되면 고객에게 다음과 같이 안내합니다.

> “카드 결제가 확인되었습니다. 주문번호는 [주문번호]입니다. [상품명] [수량]장 주문과 커스텀 내용 [내용]을 접수했으며, 준비·제작 일정은 [예상 일정]으로 안내드립니다. 시안 확인이 필요한 경우 별도로 보내 드리겠습니다.”

### 8-6. 카드 결제 실패 또는 링크 만료

결제 실패 시 고객에게 카드 정보를 다시 요청하지 않습니다.

> “결제가 완료되지 않은 것으로 확인됩니다. 카드 정보를 채팅으로 보내지 마시고, 아래 공식 결제 링크에서 다시 시도해 주세요. 링크가 만료되었으면 새 결제 링크를 발급해 드리겠습니다.”

결제 금액이 견적과 다르거나 결제 상태가 불명확하면 제작을 시작하지 않고 관리자 또는 결제대행사 확인 후 처리합니다.

### 8-7. 카드 결제 전환 금지 사항

- 카카오채널이나 전화로 카드번호를 받지 않기
- 고객에게 계좌 비밀번호나 인증번호를 요청하지 않기
- 카드 결제인데 현금 계좌이체 할인 단가로 결제 링크를 만들지 않기
- 카드 결제가 완료되기 전에 제작을 시작하지 않기
- 결제 완료 여부를 고객의 캡처만으로 확정하지 않기
- 카드 결제 금액에 임의 수수료를 붙이지 않기
- 카드 결제 취소·환불 기준을 사전에 안내하지 않고 진행하지 않기


## 9. 관리자에서 NEXTR 카드 결제 링크 생성하기

1. 관리자 화면에서 **NEXTR 결제 링크** 탭을 엽니다.
2. 상담이 끝난 고객의 단체주문 상품 ID, 수량, 고객명, 연락처, 배송지를 입력하고 **카드 결제 링크 생성**을 누릅니다.
3. 생성된 링크는 즉시 클립보드에 복사됩니다. 아래 문구에 링크를 붙여 카카오채널로 보냅니다.

> 안녕하세요. NEXTR입니다. 상담하신 단체주문 카드 결제 링크를 보내드립니다.
> 결제 금액과 주문 내용을 확인한 뒤 공식 결제창에서 결제해 주세요.
> 링크: [결제 링크]
> ※ 42,000원/39,000원 단체 할인은 현금 계좌이체에만 적용되며 카드 결제에는 적용되지 않습니다.
> ※ 카드번호·유효기간·CVC·비밀번호는 카카오채널이나 전화로 요청하지 않습니다.

카드 링크의 금액은 서버가 등록된 상품 판매가와 수량으로 다시 계산합니다. 상담자가 입력한 임의의 금액이나 현금 전용 할인가는 카드 결제 금액에 반영되지 않습니다. 링크는 기본 72시간 후 만료되고, 결제 승인 후 재사용할 수 없습니다. 관리자 화면에서 결제 전 링크를 취소할 수도 있습니다.

고객은 링크에서 주문 요약과 카드 결제 금액을 확인하고 토스 공식 결제창으로 이동합니다. 결제 승인과 주문 생성은 서버에서 토스 결제키·주문번호·금액을 대조한 뒤 처리됩니다. 결제 완료 전에는 주문이 생성되지 않으며, 새로고침·중복 승인도 서버 상태로 차단합니다.
