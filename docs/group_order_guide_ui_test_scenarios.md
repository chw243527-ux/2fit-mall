# 단체주문 안내 화면 UI 테스트 시나리오

- 대상 화면: `HOW TO CUSTOM` 단체주문 안내 화면
- 관련 화면: 단체주문 상품 상세페이지, 내부 채팅상담, 엑셀 주문서 열기·다운로드, `OUR TEAMS`
- 작성 기준: NEXTR 단체주문 안내 흐름
- 테스트 유형: UI 기능 테스트, 반응형 테스트, 콘텐츠 테스트, 접근성 테스트, 회귀 테스트

## 1. 테스트 목적

단체주문 안내 화면이 고객에게 실제 진행 순서를 정확하게 전달하는지 확인한다. 특히 카카오채널이 아닌 쇼핑몰 내부 채팅으로 연결되는지, 주문 수량에 따라 5인용·10인용 엑셀 주문서가 올바르게 선택되는지, 주문서·로고 파일 이메일 전달과 디자인 수정 2회 제한 및 제작 기간 안내가 화면에 명확하게 표시되는지 검증한다.

## 2. 테스트 환경

### 디바이스 및 브라우저

| 구분 | 권장 테스트 환경 |
|---|---|
| Android 앱 | Android 10 이상, 소형·대형 화면 각 1종 |
| iOS 앱 | iOS 16 이상, 소형·대형 화면 각 1종 |
| 모바일 웹 | Chrome Android, Safari iOS |
| 데스크톱 웹 | Chrome, Safari 또는 Edge |
| 화면 방향 | 세로 기본, 가로 전환 시 레이아웃 확인 |

### 테스트 계정 및 데이터

- 로그인 사용자 계정 1개
- 로그아웃 상태 계정 1개
- 단체주문 상품 1개 이상
- 상품명·상품번호·상품 ID·상품 유형이 모두 등록된 상품
- 주문 수량 테스트값: 4장, 5장, 9장, 10장, 20장
- 내부 채팅방 생성 및 메시지 저장이 가능한 Firebase 환경
- 5인용·10인용 엑셀 주문서 asset 파일
- 팀명 입력값 예시: `NEXTR 러닝팀`
- 주문일 예시: `2026-11-27`

## 3. 핵심 사용자 흐름

1. HOW TO CUSTOM 메뉴에 진입한다.
2. 안내 화면에서 1~9단계가 순서대로 표시되는지 확인한다.
3. 단체주문 상품 상세페이지로 이동한다.
4. `판매자에게 문의하기` 버튼을 누른다.
5. 5장 이상으로 주문 수량을 선택한다.
6. 수량 선택 후 쇼핑몰 내부 채팅방으로 연결되는지 확인한다.
7. 첫 상담 메시지에 상품 정보와 상담 수량이 자동 포함되는지 확인한다.
8. 수량에 맞는 엑셀 주문서가 선택되고 앱에서는 열기·공유 창, 웹에서는 다운로드가 동작하는지 확인한다.
9. 주문서·로고 파일 이메일 전달, 판매자 확인, 디자인 제작·수정·최종 확정·제작·배송 안내가 화면 내용과 일치하는지 확인한다.

### 주문서 파일 검증

- 5인용 선택 시 `nextr_singlet_order_form_5_plus.xlsx`가 사용된다.
- 10인용 선택 시 `nextr_singlet_order_form_10_plus.xlsx`가 사용된다.
- 웹 다운로드 파일이 0바이트가 아니고 Excel에서 열리는지 확인한다.
- 앱에서 공유·열기 창이 표시되는지 확인한다.
- 파일명은 주문일과 팀명을 포함하는 규칙을 적용한다. 예: `2026-11-27_NEXTR 러닝팀_단체주문서.xlsx`
- 파일명에 `/`, `\\`, `:`, `*`, `?`, `"`, `<`, `>`, `|` 등 운영체제 금지 문자가 입력될 때 안전하게 치환되는지 확인한다.
- 동일 팀이 같은 날 여러 번 다운로드해도 파일 덮어쓰기 또는 중복 저장 동작이 사용자에게 명확해야 한다.

## 9. 접근성 및 사용성 테스트

- 모든 주요 버튼을 키보드 Tab으로 접근할 수 있는지 확인한다.
- `판매자에게 문의하기` 버튼의 포커스 상태가 시각적으로 구분되는지 확인한다.
- 버튼과 배경의 색상 대비가 충분한지 확인한다.
- 단계 번호만으로 의미가 전달되지 않고 제목·설명이 함께 제공되는지 확인한다.
- 스크린 리더가 단계 번호, 제목, 설명을 자연스러운 순서로 읽는지 확인한다.
- 엑셀 주문서 다운로드 또는 열기 후 다음 행동이 무엇인지 사용자가 이해할 수 있는지 확인한다.
- 오류 메시지가 단순히 실패했다고만 표시되지 않고 올바른 수량 범위를 안내하는지 확인한다.
- 로딩 중 중복 클릭으로 채팅방이나 다운로드가 여러 번 실행되지 않는지 확인한다.

## 10. 회귀 테스트

- 일반 기성품 상품의 구매·장바구니·결제 흐름이 영향을 받지 않아야 한다.
- 단체주문 상품의 상세페이지 가격·상품명·이미지·섹션이 정상 표시되어야 한다.
- 관리자 채팅방 목록에서 단체주문 상담 필터와 배지가 정상 동작해야 한다.
- 관리자 답변·상담 완료·상담 재개 기능이 정상 동작해야 한다.
- 웹 직접 URL 접근 시 상품 상세페이지 라우팅이 홈으로 잘못 fallback되지 않아야 한다.
- 앱과 웹 모두 기존 공유 기능과 카카오톡 상품 공유 기능이 정상 동작해야 한다. 단, 판매자 문의 기능은 내부 채팅으로 연결되어야 한다.
- 앱 빌드·웹 빌드에서 제거된 `url_launcher` 단체주문 호출에 따른 컴파일 오류가 없어야 한다.

## 12. 완료 기준

다음 조건을 모두 충족하면 단체주문 안내 화면 UI 테스트를 완료한 것으로 판단한다.

1. `HOW TO CUSTOM` 화면의 1~9단계 콘텐츠가 순서와 문구 모두 요구사항과 일치한다.
2. 단체주문 CTA가 카카오채널이 아닌 쇼핑몰 내부 채팅으로 연결된다.
3. 상품명·상품번호·상품 ID·상품 유형·상담 수량이 상담방에 자동 전달된다.
4. 5~9장과 10장 이상 주문서 분기가 정확하다.
5. 앱 열기·공유 및 웹 다운로드가 모두 정상 동작한다.
6. 다운로드 파일명이 주문일과 팀명을 포함한다.
7. 소형 모바일 화면에서 텍스트 겹침·잘림·가로 오버플로가 없다.
8. OUR TEAMS 빈 상태와 이미지 오류 상태가 안전하게 표시된다.
9. 관리자 화면에서 신규 단체주문 상담을 확인할 수 있다.
10. Flutter CI, Dart Analyze, 웹 배포 및 Android 내부 테스트 파이프라인이 성공한다.
