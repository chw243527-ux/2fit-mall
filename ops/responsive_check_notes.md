# 반응형 화면 검증 메모

점검일: 2026-08-29

- 390x844 모바일 캡처: 로그인 화면이 정상 렌더링되었고 입력창·로그인·카카오 로그인 영역이 화면 안에 배치되었다. 하단 PWA 설치 안내가 Google 로그인 영역과 겹치는 시각적 문제가 확인되었다.
- 768x1024 태블릿 캡처: 사이트가 `ERR_SSL_PROTOCOL_ERROR`로 로드되지 않았다. 이는 레이아웃 문제 이전에 해당 화면 폭 검증을 막는 운영 접속 오류다.
- 추가 PC 캡처는 별도 확인이 필요하다.

PC 1280x800에서는 로그인 화면이 좌우 2단으로 정상 렌더링되었고 주요 입력·로그인 버튼이 잘리지 않았다. 899x900 태블릿 경계 폭에서도 `ERR_SSL_PROTOCOL_ERROR`가 재현되어 레이아웃 검증 자체가 불가능했다. 모바일 390px에서는 로그인 화면이 정상이나 하단 PWA 설치 안내가 Google 로그인 영역과 시각적으로 겹쳤다.

추가 분석 결과, 일반 브라우저 세션에서는 `https://2fit-mall.co.kr/`가 정상적으로 TLS 연결되고 로그인 화면이 표시되었다. 동일 환경의 curl과 원본 `twofit-mall.pages.dev` 모두 Cloudflare TLS 단계에서 `tlsv1 alert access denied`를 반환했다. 따라서 이전 태블릿 캡처의 `ERR_SSL_PROTOCOL_ERROR`는 화면 폭별 앱 레이아웃이 아니라 헤드리스·명령줄 측정 클라이언트가 Cloudflare 엣지에서 차단된 현상으로 판단된다. 도메인 인증서 만료나 사용자 도메인과 Pages 원본 간 인증서 불일치는 확인되지 않았다.
