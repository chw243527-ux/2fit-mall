2FIT MALL 계정 삭제 요청

2FIT MALL 계정과 관련 데이터의 삭제 방법을 안내합니다.

앱에서 계정 삭제하기

  1. 2FIT MALL 앱 또는 웹사이트에 로그인합니다.
  2. 마이페이지로 이동합니다.
  3. 회원정보 또는 계정 설정에서 회원 탈퇴를 선택합니다.
  4. 탈퇴 사유를 선택하고 계정 삭제를 확인합니다.

로그인할 수 없는 경우

비밀번호 분실, 휴대전화 변경 등으로 로그인할 수 없으면 아래 이메일로 계정 삭제를 요청할 수 있습니다.

계정 삭제 요청 이메일 보내기

요청 시 가입 이메일 또는 전화번호를 적어 본인 확인에 필요한 정보를 제출해 주세요. 비밀번호와 인증번호는 이메일에 적지 마세요.

삭제되는 데이터

  • 회원 프로필 정보와 로그인 연결 정보
  • 배송지와 연락처 등 프로필성 정보
  • 업로드한 디자인·로고·첨부파일
  • FCM 푸시 알림 토큰
  • 탈퇴 사유의 개인 식별 정보가 제거된 서비스 개선용 통계

법정 보존이 필요한 기록

전자상거래 관련 법령에 따라 보존이 필요한 주문·결제·환불 기록은 필요한 기간 동안 개인 식별 정보를 최소화하거나 비식별화하여 보관할 수 있습니다. 보존 기간이 지나면 해당 기록도 삭제 또는 추가 비식별화합니다.

처리 기준

앱에서 직접 탈퇴한 경우 요청 즉시 삭제 절차가 시작됩니다. 이메일로 접수된 요청은 본인 확인 후 처리하며, 처리 결과는 요청 이메일로 안내합니다.
